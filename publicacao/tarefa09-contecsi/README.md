# 🧪 Atividade 09 — Submissão CONTECSI

## Informações Gerais
- **Modalidade selecionada:** PSE — Artigo Completo (Full Paper)
- **Justificativa da escolha:** A pesquisa superou a fase inicial e gerou dados empíricos robustos sobre o comportamento de arquiteturas em nuvem (Bottleneck Shifting), justificando uma discussão técnica aprofundada que não caberia no formato restrito de um Resumo Expandido (REX).
- **Título do Trabalho:** Modelagem e Avaliação de Arquitetura de Software para Sistemas Web Escaláveis
- **Breve descrição da contribuição científica:** O artigo comprova empiricamente que, em ambientes cloud-native serverless, a escalabilidade irrestrita da camada de computação (Fargate) garante 100% de disponibilidade, mas desloca o gargalo de processamento para a camada de persistência de dados relacional (RDS), impedindo o cumprimento estrito do SLA de latência.
